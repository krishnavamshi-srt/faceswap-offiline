# Multiple Face Swap (works offline)
1. Create a new PUBLIC GitHub repo.
2. In the repo go to Settings > Pages > Source > choose "GitHub Actions".
3. Upload everything in this folder (including the hidden .github folder).
4. Open the Actions tab, wait for the green tick, then open https://YOUR-USERNAME.github.io/REPO-NAME/
5. Stay on the page on the first visit until the model loads. After that it works offline.
